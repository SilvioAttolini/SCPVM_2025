# SCPVM_2025

SCPVM - Spatial Coherence Parametric Virtual Miking

## Features

- Adds SC constraints to diffuse component synthesis using Habets' algorithm
- DRR study for manually chosen optimal Wiener filter

## Installation

git clone https://github.com/SilvioAttolini/SCPVM_2025.git

## Run
Execute the file "demo_parametric_vm.m"
